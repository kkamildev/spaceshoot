# Spacehoot - spaceship game
## 📂 About project:
Game made using ```C# language and XNA framework (for making games)```  
Game is about spaceship which must survive waves of enemy ships  
Game don't have ending (endless waves)  
Game save best wave to ```application folder```
## 🎮 Game mechanics
  - Control your spaceship using ```mouse``` and keys ```W``` to accelerate and ```S``` to brake
  - Fire a laser using ```SPACE```, aim to the incoming enemies
  - Each wave has different count of enemy spaceships, after destoying all, wave is completed and new wave countdown is in progress
  - You can also use collected item using ```E```
  - best wave is saved after game over, best wave displays in ```game menu```
## ⚙️ Run project:
- You must install ```.NET 6.0``` or above to run this project
- Clone this repository using:
```
git clone https://github.com/Kamil-Kijak/spaceshoot.git
```
- Enter to cloned folder and run this project using:
```
dotnet run
```
